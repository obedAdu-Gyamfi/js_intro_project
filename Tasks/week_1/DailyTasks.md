# Week 1: JavaScript Fundamentals

This companion page expands the Week 1 roadmap in the root [README](../../README.md). Every task produces a runnable `.js` file under `src/day_NNN/`.

| Day | Build | Core concepts |
|---|---|---|
| 1 | Student profile | `console.log`, `const`, `let`, templates |
| 2 | Unit converter | Primitives, operators, `Number`, `NaN` |
| 3 | Eligibility calculator | Comparisons, `if`/`else`, boolean logic |
| 4 | Multiplication table | `for`, `while`, `for...of` |
| 5 | Shopping-list manager | Arrays and array methods |
| 6 | Text analyzer | Strings, templates, normalization |
| 7 | Command-line quiz | Composition, validation, checkpoint review |

## Daily Deliverables

- A runnable entry point such as `src/day_001/index.js`.
- A short `src/day_001/README.md` explaining the objective and approach.
- At least one normal-case and one edge-case check.
- A note about one concept that became clearer through practice.

Run the starter example from the repository root with `node src/day_001/index.js`.
